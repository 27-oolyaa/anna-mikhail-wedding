# Свадебное приглашение — Анна & Михаил

## Файлы
- `index.html` — сайт.
- `styles.css` — оформление и адаптивность.
- `script.js` — таймер, меню, анимации и отправка RSVP.
- `Code.gs` — обработчик Google Apps Script.

## RSVP уже настроена на опубликованный Google Apps Script
В `script.js` уже добавлен URL веб-приложения. При отправке формы ответы должны добавляться на лист «Ответы гостей» в привязанной Google Таблице.

## Публикация обновлённого сайта
Загрузите содержимое этой папки на Netlify вместо старой версии сайта. Если Netlify просит архив, используйте ZIP.

## Проверка
После публикации откройте сайт, отправьте тестовый RSVP с тестовым именем, затем проверьте лист «Ответы гостей» в Google Таблице.

Важно: у Apps Script доступ к веб-приложению должен быть настроен на «Все», выполнение — от имени владельца. Не делитесь самой таблицей публично.
