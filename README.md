# Анна & Михаил — свадебное приглашение

## Состав
- index.html — страница приглашения
- styles.css — стили и адаптивность
- script.js — таймер, анимации, RSVP
- Code.gs — обработчик Google Apps Script

## Важно: подключение RSVP
В `script.js` уже указан новый URL опубликованного веб-приложения Google Apps Script.
В `Code.gs` уже указан ID Google Таблицы.

После замены `Code.gs` в редакторе Apps Script обязательно сохраните проект и создайте новую версию развертывания:
Развернуть → Управление развертываниями → карандаш → Новая версия → Развернуть.
Доступ: Все; выполнять от имени владельца.

Затем загрузите `index.html`, `styles.css` и `script.js` в корень GitHub-репозитория. `Code.gs` загружается в редактор Apps Script, а не в GitHub Pages.

После отправки тестовой RSVP проверьте лист «Ответы гостей».
