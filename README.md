# Свадебное приглашение — Анна & Михаил

## Файлы
- `index.html` — сайт.
- `styles.css` — оформление.
- `script.js` — таймер, анимации и отправка RSVP в Google Apps Script.
- `Code.gs` — серверный обработчик Google Apps Script.

## Важно: обновление GitHub Pages
Загрузите `index.html` и `script.js` из этого архива в корень репозитория GitHub, заменив старые файлы, затем нажмите Commit changes. `styles.css` менять не требуется.

Форма отправляет поля `name`, `attendance`, `plusOne`, `comments` в указанный URL Google Apps Script.
Проверьте, что развертывание Apps Script доступно всем и выполняется от имени владельца.
